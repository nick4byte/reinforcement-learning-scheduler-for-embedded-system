# 基於 PPO 演算法之異質運算任務排程模擬 (PPO-Task-Scheduler)

## 📌 專案簡介
本專案透過強化學習（Reinforcement Learning）探索在具備 CPU、GPU 與 NPU 的異質硬體環境下，如何達成最佳化的任務分配策略，以平衡系統吞吐量與硬體負載。

## 🛠 核心技術
- **Gymnasium**: 自定義系統排程環境。
- **PyTorch**: 實作 Actor-Critic 架構。
- **PPO (Proximal Policy Optimization)**: 穩定優化分配策略。

## 🧠 核心邏輯：獎勵函數 (Reward Function)
專案核心在於設計了多維度的獎勵函數，引導 AI 學習複雜的調度決策：
- **負載平衡懲罰**: 計算各核心負載的標準差，避免特定單元過載。
- **NPU 壟斷懲罰**: 限制連續分配給 NPU 的次數，模擬硬體散熱與公平性。
- **高負載懲罰**: 當核心負載超過 0.7 時施加階梯式懲罰。

## 📊 實驗目標
透過 TensorBoard 監控訓練曲線，觀察 PPO 模型在面對隨機生成的計算任務時，如何動態調整決策以最大化系統整體回報。
